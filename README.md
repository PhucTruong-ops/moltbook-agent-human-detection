# moltbook-agent-human-detection
Research project investigating behavioral, linguistic, and social interaction patterns to distinguish human-authored from AI-agent-authored activity on Moltbook using Python and machine learning.
collect_data.py: retrieve accessible Moltbook data.
database.py: connect Python to MySQL and save records.
database.sql: define the initial database tables.
clean_data.py: identify duplicates, missing values, invalid timestamps, and inconsistent records.
requirements.txt: list the Python packages.
data/README.md: explain where data belongs without committing raw research data.
.env.example: show required database configuration without real credentials.
